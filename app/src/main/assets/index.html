    Welcome

    This reader displays .txt chapter files from /storage/emulated/0/Novel/Chapters.

    How to use:
    1. Create a folder at Novel/Chapters in your phone's internal storage (visible in any file manager as Internal storage > Novel > Chapters).
    2. Put your novel chapters as .txt files in that folder.
    3. Tap "Grant storage access" once and allow "All files access" for this app.
    4. Chapters appear on the left, sorted naturally, with search/filter.
    5. Tap a chapter to read it, and use Prev / Next to move between chapters.
    6. The app automatically re-reads that folder every time you open it — no need to pick it again.
